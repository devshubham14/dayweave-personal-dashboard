# Dayweave Personal Dashboard

Act as a senior product designer and frontend engineer at a world-class SaaS company.

Design and develop LIFEOS, a premium personal productivity and life management platform.

CORE DESIGN OBJECTIVE:

The application must look like a professionally designed commercial SaaS product, not an AI-generated template, generic admin dashboard or futuristic concept website.

DESIGN INSPIRATION:
Take inspiration from Linear, Notion, Raycast and Stripe.

Do not copy their interfaces. Create an original and cohesive LifeOS design identity.

VISUAL STYLE:

- Minimalist.
- Premium.
- Professional.
- Clean.
- Elegant.
- Functional.
- Excellent visual hierarchy.
- Consistent spacing.
- Thoughtful typography.
- Subtle micro-interactions.

COLOUR SYSTEM:

Primary background: #F8FAFC
Sidebar: #FFFFFF
Cards: #FFFFFF
Primary text: #172033
Secondary text: #64748B
Accent: #6366F1
Borders: #E8ECF2

Use a restrained colour palette.

Avoid:
- Excessive gradients.
- Neon colours.
- Glassmorphism everywhere.
- Glowing borders.
- Floating decorative objects.
- Excessive rounded cards.
- Unnecessary animations.
- Oversized headings.
- Generic AI dashboard layouts.

TYPOGRAPHY:

Use Geist or Inter.

Create a consistent typography scale with clear heading hierarchy.

LAYOUT:

Create a fixed-width desktop sidebar with:
- LIFEOS wordmark.
- Overview.
- Tasks.
- Study Planner.
- Expenses.
- Habits.
- Calendar.
- AI Assistant.
- Analytics.
- Settings.

MAIN DASHBOARD:

Header:
- Personalised greeting.
- Current date.
- Search.
- Notifications.
- Profile menu.

Welcome section:
- Short personalised greeting.
- Today's date.
- Daily progress indicator.

STATISTICS:
- Completed tasks.
- Study hours.
- Pending tasks.
- Monthly expenditure.

MAIN CONTENT:
- Today's schedule.
- Priority tasks.
- Weekly productivity chart.
- Upcoming deadlines.
- Recent activity.

ADDITIONAL PAGES:

1. Task management.
2. Study planner.
3. Expense tracker.
4. Habit tracker.
5. Calendar.
6. AI assistant.
7. Productivity analytics.
8. Settings.

FUNCTIONAL REQUIREMENTS:

- Working navigation.
- Reusable components.
- Consistent design system.
- Responsive layouts.
- Realistic sample data.
- Functional demo interactions.
- Proper empty states.
- Loading states.
- Error states.

TECHNOLOGY:

React, TypeScript, Tailwind CSS and Lucide icons.

Use clean component architecture and maintainable code.

IMPORTANT:

Prioritise usability and visual quality over decoration.

Every element must have a clear purpose.

The final product should look like a real productivity SaaS application designed by an experienced product design team.
